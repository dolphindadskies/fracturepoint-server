# Fracturepoint server rules

Fracturepoint is a survival, exploration, community, building, and PvP server.
PvP is enabled; claims protect homes, containers, and discoveries.

1. No hacked clients, movement/combat cheats, x-ray, dupes, or exploit abuse.
2. No claim bypass, theft from protected claims, or destruction of expedition
   arrival anchors, rescue spines, hubs, signs, or other safety infrastructure.
3. PvP is allowed. Spawn camping, repeated targeted harassment, hate speech, and
   using bugs to trap a player without a recovery route are not.
4. Do not intentionally create lag machines or mass-generate frontier cells.
5. Moderator action uses server evidence. Anti-cheat alerts alone are not treated
   as infallible proof; Ledger history and relevant logs are preserved first.

Use `/expedition return` if an expedition landing becomes unsafe. Report the
realm, direction, paid stop, time, and player names for any incident.

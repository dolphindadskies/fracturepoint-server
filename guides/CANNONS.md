# Cannon guide: pearl launcher and orbital cannon

Learn the original designs behind Fracturepoint's pearl launcher and orbital cannon. Start with the creator videos and matching schematics below. For joining and proximity voice, see the [installation guide](../downloads/README.md).

## Shared Far Lands pearl launcher

The physical foundation is **Nugglz's Ender Pearl Cannon V2**:

- [Watch the original Nugglz V2 video](https://www.youtube.com/watch?v=fySWaBWxQZ4).
- [Get the original schematics](https://www.mediafire.com/folder/yqxztedgssv6w/Ender_Pearl_Cannon_v2_Nugglz).

The video and schematics teach the original design. Fracturepoint's shared launcher is modified for 26.2 with a custom physical aligner, server controller and scoped optimizations. The original video is a foundation, not an exact tutorial for this modified launcher, and it does not guarantee Far Lands range. A complete public 26.2 build manual for our modified launcher has not yet been published.

### Using the shared launcher

Follow the numbered signs at the launcher:

1. Use the loading booth and throw **one pearl** as its sign shows.
2. Turn **ALIGN on**, leave it on, and wait for the status sign to confirm alignment. If it reports a problem, do not start charging.
3. Turn **CHARGE on** once. Wait for **CHARGE ARMED**, then follow the marked portal route.
4. Stay online in the Nether waiting station. Wait for **READY** and the return gate to open; do not return early.
5. Drink **Slow Falling before entering the return portal**. Follow the landing instructions at the station.

Use the status signs, rather than a chat reply or a fixed wall-clock timer. If a charge pauses, ask for help before using RESET; resetting a partially charged bank can lose its progress.

## Orbital cannon

The physical design is **cubicmetre's Orbital Strike Cannon**, built on Fracturepoint by **Dolphindadskie**. The published Mk 6.1 design uses real TNT and rings, with targets programmed in advance. Its fishing-rod remote is for release only; it does not provide a chargeable, roaming, free-aim targeting rod.

- [Watch cubicmetre's original video](https://www.youtube.com/watch?v=q78LRgHt_zU): controls at **44:03**, rod magazine at **49:32**.
- [Get the original schematics](https://www.mediafire.com/folder/p9dugihg28wnr/Orbital_Strike_Cannon_6.0).
- [Use the orbital fire-control calculator](https://osc-fire-control.cubicmetre.net/).

The shared orbital installation is not open for player operation yet. The links teach the original physical design and programmed-target controls; they are not instructions for charging a rod that can target anywhere you look.

### Why does Wemmbu's version look different?

[Wemmbu's orbital-cannon video](https://www.youtube.com/watch?v=oBZ7ydMaQis) credits cubicmetre for the cannon design. Its description also explains that the video is staged and that some Unstable mechanics differ from, or do not exist in, vanilla Minecraft. We have not verified a public 26.2 build guide or released implementation for the complete **build cannon → charge several rods → roam and cast at a target** sequence. That sequence is not currently a Fracturepoint feature.
